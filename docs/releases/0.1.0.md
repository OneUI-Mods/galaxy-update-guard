# Galaxy Update Guardを公開

Samsung GalaxyのOSアップデートを、スイッチで停止・復元できるアプリです。停止前の設定を保存し、OFFではその状態へ戻します。一時rootが外れた後もブロックは維持されます。

Android 16・17、Samsungの標準OS更新サービスを使う端末のメインユーザー向けです。変更にはrootが必要です。Google Playシステム更新とアプリ更新は対象外です。すでに適用中の更新、別の更新サービスを使うキャリア版、USB・リカバリー経由の更新には対応しません。

署名済みrelease APKをインストールしてください。端末の再起動やXposedの設定は不要です。アプリの削除・データ消去前には、停止前の状態へ戻してください。
